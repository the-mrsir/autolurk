Channel points

AutoLurk clicks the bonus chest in Twitch's channel points widget. It never spends points. Because Twitch rounds the displayed balance past a thousand, a claim is counted only when the chest disappears, not from the number.

When a favorite's watch streak is expiring, AutoLurk opens that channel's recovery clip or VOD. Bringing it to the front is what lets the video actually start. The recovery tab closes once Twitch's own streak query no longer shows an expiration.

7TV

Looks up each live favorite's 7TV emote set and shows it under Details. Results are cached for six hours, so this is a couple of requests an hour.

Your other computers

This computer makes a sync code. Favorites and settings are shared with other computers on the same Chrome profile that use this code. Paste a code from another computer to join its set. The Twitch login stays on each computer. Open streams stay on this one.

Both computers must show the same extension ID below. Chrome keys synced data to this ID, so if they differ, neither machine can see the other.

Updates

Chrome does not update an extension loaded from a folder, and it will not let a page write into that folder. Check reads the GitHub repository. When that version is higher, pull this folder if it is the git checkout, or replace the folder, then click Reload on chrome://extensions. The first Check lets Chrome reach GitHub.

To publish an update, raise the version in manifest.json and push. A JSON address with version and packageUrl still works too.
